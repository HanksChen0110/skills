# 当前启用的 Skills

本仓库同步 CC Switch 当前激活的通用 Skills，用于多设备更新。当前快照日期：2026-10-03。

## 发布范围

- 当前包含 **142 个 Skill 包**；任一工具中已启用即纳入仓库。
- Claude Code：141 个；Codex：141 个；Gemini：17 个。
- 未激活的 Skill 不出现在当前版本中，可从 Git 历史恢复。
- Skill 包内部的子技能、引用资料、脚本和资源随所属包保留。
- 不包含依赖安装目录、缓存、日志及本地凭据配置；运行依赖和凭据在目标设备配置。

[目录清单](.skill-allowlist.txt)列出当前发布的目录；[启用状态清单](active-skills.json)记录各工具的开关，便于另一台设备恢复配置。

## 在另一台设备更新

1. 在 CC Switch 的 Skill 仓库来源中添加或更新 `HanksChen0110/skills`，分支为 `main`。
2. 导入或更新本仓库中的 Skill，通过 CC Switch 分发到需要使用的工具。
3. 参考 `active-skills.json` 恢复各工具的启用状态；另一台设备原有的额外 Skill 是否停用，由该设备单独决定。

拉取仓库只更新文件，不会自动修改另一台设备的 CC Switch 开关。不要用另一台设备的完整管理数据库覆盖本机配置。

## 维护约定

以 CC Switch 当前启用状态和唯一源目录为准发布。第三方 Skill 的原有许可证、出处及必要资源随包保留。只做正常提交和推送，不重写历史。
