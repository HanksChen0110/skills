# 逻辑谬误 + 推理型认知偏误

审查"想得对不对"的第二层：论证链是否成立，思考是否被系统性偏误带偏。审到就查表，命中就按格式报。

## 目录
- 一、逻辑谬误清单
- 二、推理型认知偏误清单
- 三、检查顺序建议

## 一、逻辑谬误清单

逐条对照论证链，看有没有踩中：

| 谬误 | 识别信号 |
|---|---|
| **偷换概念** | 前后同一个词含义变了（"用户"一会指付费用户一会指所有访客） |
| **稻草人** | 反驳的是对方没说过的、被夸大的版本 |
| **滑坡** | "一旦…就必然…最终…"，中间环节没论证 |
| **虚假两难** | 只给两个选项，其实还有第三条路 |
| **因果倒置/相关当因果** | A 和 B 同时出现就断定 A 导致 B |
| **循环论证** | 结论被当成前提用（"它好卖因为它是好产品"） |
| **诉诸权威/流行** | "专家说""大家都用"当作论据本身 |
| **以偏概全** | 用个例/小样本推出普遍结论 |
| **举证责任倒置** | "你不能证明它不行，所以它行" |
| **轶事证据** | 用"我认识一个人…"代替数据 |

**报法**：指出哪句话、哪个环节踩了哪个谬误，给出它为什么不成立。

## 二、推理型认知偏误清单

这些偏误影响"判断准不准"（源自《思考，快与慢》系统1的快思考）。逐条自检：

| 偏误 | 表现 | 审查追问 |
|---|---|---|
| **确认偏误** | 只找支持自己的证据，忽略反例 | "有没有找过反对的证据？最强的反例是什么？" |
| **锚定效应** | 被第一个数字/初始方案锚住 | "这个数字/起点是怎么来的？换个锚会不会结论不同？" |
| **可得性偏误** | 用最近、最好想起的例子代替真实概率 | "这是普遍情况还是你印象最深的个案？有分布数据吗？" |
| **沉没成本** | 因为已投入而不肯放弃 | "如果今天从零开始，你还会选这条路吗？" |
| **过度自信** | 对预测/估算过于笃定 | "如果错了，最可能错在哪？给个置信区间。" |
| **代表性偏误** | 靠"像不像"下判断，忽略基础概率 | "符合直觉，但底层的基础比率是多少？" |
| **框架依赖** | 同一事实换个说法结论就变 | "换成损失/收益的另一种说法，判断还一样吗？"（决策类偏误详见 persuasion-decision.md） |
| **事后诸葛/后见之明** | "我早就知道会这样" | "当时真有证据，还是结果出来才这么说？" |

## 三、检查顺序建议

先过逻辑谬误（论证结构是否成立），再过推理偏误（判断是否被带偏）。结构塌了就不用细究偏误——直接标致命。两者都指向"结论不可靠"，但结构问题更硬。
